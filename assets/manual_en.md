# Scholarship & Document Checklist

## Create a package
1. On the **Overview** page click **+ New package** (or press `Ctrl+N`).
2. Choose a template (for example *President scholarship*). Untick documents you don't need.
3. Enter the deadline, organization and notes, then click **Save**.

## Work with documents
- On the **Packages** page select a document and set its status with the buttons:
  *Needed*, *In progress*, *Ready*, *Submitted* (keys `1`–`4`).
- Drag a file from Explorer onto a row, or click **Attach file**.
- **Open file** and **Open folder** show the attached file. A missing file is shown in red.
- Double-click or press `F2` to edit a document. `Del` removes it from the list.

## Prepare the submission
- **Collect to folder** copies all attached files into a new folder with names like `01_Application.pdf`.
  The original files are not changed.
- The **Export** menu saves the checklist as PDF or Excel.

## Templates
On the **Templates** page edit the list (one document per line) or create your own template.
**Restore built-in** resets the built-in templates.

## Reminders
On the **Settings** page choose how many days before a deadline to be reminded. Windows notifications appear
while the app is open or running in the tray. Closing the window hides the app to the tray; use **Quit** in the
tray menu to exit. Autostart is only enabled if you tick it yourself.
